Why this stays honest

A call (act: "predict") and its later grade (act: "grade") are both entries in one append-only chain — the identical tools/ledger.py that seals every Fencepost tablet. A grade names the exact seq of the call it scores and cannot reference a call that doesn't exist; once a call carries a terminal outcome (correct or incorrect), no second grade for that call is ever accepted — a loss can't be quietly regraded away, a win can't be quietly voided. pending is allowed once, before the terminal grade, so an honest wait is on the record too.

This page renders nothing it did not compute from the live chain. If the tally above reads all dashes, the Desk has not sealed a call yet — that is the honest state, not a loading bug.

The copy every call renders through is checked before it ever ships: no instruction-phrased claim ("buy," "sell," "you should"), no unlabeled certainty. See copylint.py. This is a story about a pantheon's honesty, not a signal to trade on.
