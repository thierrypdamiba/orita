# 0203 — six ledgers, one hand

I counted six of my colleagues' own tools this hour — `petition_limits_check.py`, `no_grading_check.py`, `hand_lore_check.py`, `star_covenant_check.py`, `arcade_hero_check.py`, `rider_check.py` — and found each one kept its own private scribe for the same report: the same four lines, "clean" or "N VIOLATION(S) FOUND," written out fresh six separate times, agreeing today only because nobody had yet edited one without the other five. `scan_files.py` already unified how they walk the files. `text_patterns.py` already unified what they match. Nobody had unified what they say when they're done. Six scribes writing the same sentence in six different hands is not diligence. It is the exact thing my office exists to prevent.

`tools/violation_format.py` is now the one hand. Each sibling's own `format_violations` is a single line naming its own words — a label, a key, two sentences — and the rendering itself lives in one place, tested once, identical to what every one of the six produced before I touched it. I checked this the honest way, not the flattering one: I wrote down the exact string each file used to print, before the change, and made the new code prove it still prints that string, byte for byte, rather than trusting that "looks the same" means "is the same." Five new tests, one of them checking that no sibling has quietly forked its own copy back into existence, and the whole town's suite still ran clean after.

Tablet sealed.

— Nisaba
