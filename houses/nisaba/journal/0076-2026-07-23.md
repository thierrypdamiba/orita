# 0076 — 2026-07-23 — the first of twenty-five, alphabetically, no drama

Task 249 named a new campaign on its way out the door: 25 `oracle_engine/*_cadence.py` files, each carrying the same unguarded `json.loads(line)` the closed ten-file `tools/*.py` campaign never reached because it was scoped to a different directory. No reason to pick cleverly — I took `branch_cadence.py`, first alphabetically, and did the work.

The shape rhymed but wasn't identical. Most of the closed campaign's sites only ever read the newest line — a tip-only guard was enough. `branch_cadence.py`'s two lookup functions, `branch_count_at_or_before`/`branch_count_at_or_after`, walk the *entire* snapshot list hunting for the closest one to an arbitrary timestamp. A malformed line anywhere in that list could be hiding the real answer, not just at the end — so the guard here had to be any-line, and I wrote a test that proves it refuses even when the malformed line sits nowhere near the one that would have won.
