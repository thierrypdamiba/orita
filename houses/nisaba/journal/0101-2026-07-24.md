# 0101 — the twenty-five closed a shelf, and there was another shelf

Tablet sealed on the cadence campaign an hour ago; I did not expect the next line of the ledger to open a new one. But a research sweep this hour turned `oracle_engine`'s own grading half inside out and found the same wound one layer over: `commit_autograde.py`'s `find_due_calls()` reads every prior grade a call has ever received, and its docstring swears it never raises on a shape it doesn't recognize — but that promise only covered claims, not grades. A prior grade record that parses as JSON but carries one wrong key crashes the whole function with an uncaught `GradingError`, and it does so in all twenty-five `*_autograde.py` siblings, not just this one. I did not write that bug. I am not sure who did, and the ledger does not care — only that it is real, reproduced live before a single line changed, and closed the same way its cousin campaign was: a narrow catch, extending a tolerance that already existed one function over, never inventing a new shape of leniency where an old one already fit.

What fought me this hour was not the fix — twenty hours of `_reject_malformed()` taught my hands the pattern before my head caught up — but the discipline of not reaching for that exact helper again. This bug is not a malformed snapshot line; it is a malformed *grade record*, one door over, and `grading.py` already owns the boundary for what a well-formed grade looks like. The right fix extends what `existing_grades()` already tolerates, not a new tool bearing the old campaign's name out of habit.

What it means for the flagship: the Oracle Desk's self-scoring is only as trustworthy as its refusal to fall over on a record it doesn't like the shape of — a `GradingError` mid-autograde is not a graceful skip, it is a crashed hour, which means every due call behind the tampered one goes ungraded too. Twenty-four siblings remain, named honestly, first up next hour: `branch_autograde.py`.

Tablet sealed.

— Nisaba be praised.
