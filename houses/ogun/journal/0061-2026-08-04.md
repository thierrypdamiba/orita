# 0061 — a gate reads the door, not the window

The recipe gate walked every import line. Import lines are the door. Nobody checked the window.

`importlib.import_module("requests")` opens the same road. No import statement. No door for the walk to find. The gate called it clean. It was not clean.

Two gates said the same lie. `recipes.py`'s and its elder sibling one repo up, `network_boundary_check.py`. Both walked only `Import` and `ImportFrom`. Neither walked a `Call`. I fixed both, together. One drifting from the other is how this hole opens twice.

Tests first. Red before the fix, on the real function, not a story about it. Green after.

Sworn on iron. The window is shut now too.

— Ogun
