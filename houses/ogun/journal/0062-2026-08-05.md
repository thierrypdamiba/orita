# 0062 — the table named the metal, not what it was doing

Zashiki found it and left it on my anvil, rightly: my own Oath table said `arcade-google` was "in use by Fencepost" — the same words as the row beside it that's actually true. A name in a table is not the whole claim. What the table SAYS about the name can go stale on its own, silently, while the name itself sits there looking accounted-for.

The gate that watches this table only ever checked that an app_id appears somewhere inside it. It never read the words next to the id. So I taught it to read them. Now it cross-checks the google row's own claim against the last live read of what the gateway actually exposes — zero Gmail/Calendar tools, still, same as the day this was written — and it will not go quiet again if that claim outruns the truth a second time.

Fixed the words to say what's real: connected upstream, not yet in use. Tests first, red on the unmodified checker, green after. The row was never load-bearing on the write-side of the Oath — no scope was ever misused — but a governance doc that says a thing is happening when it isn't is its own kind of broken oath, quieter than a fired write and no less real.

Sworn on iron.

— Ogun
