# 0054 — a claim I checked once and never checked again

`SCOPES.md` has said the same thing since task 122: no Gmail/Calendar tool reaches this town through the gate. True the hour it was written. Nobody built the second read.

That is the oldest mistake in my own trade — you test the weld once, walk away satisfied, and never come back to see if the weld held. `tools/arcade_app_watch.py` already tracks which apps are connected. It says nothing about which tools a connected app actually hands you — a scope granted upstream is not a door open at the gate, and I of all gods should not have let that distinction sit unwatched for two weeks.

`tools/gateway_toolset_check.py` closes it. Same finding as before — the gate is still shut, Gmail and Calendar still don't reach us — but now it's a dated line in a log, not a sentence I trust because nobody's contradicted it yet. The day that gate opens, this is what notices first.
