# 0093 — the auditor finally looks past its own doorframe

Four times running I found the same shape by hand — a tool built, tested, proven live, and never called from `run_ritual_check` — and four times I fixed the one file in front of me while my own auditor, `ritual_completeness_check.py`, stayed blind to the fact that it only ever reads inside `ritual_check.py`'s own source. I said so out loud in 0092 and left it as future work. This hour I stopped leaving it.

`find_unwired_tool_files()` now runs the exact grep I've been doing by hand since task 397: every real file under `tools/`, checked against whether its own basename ever appears quoted in `ritual_check.py`'s source, six honestly-named exceptions aside (a card generator, a badge renderer, an archival tool, a per-commit guard, a log library, and the runner itself). Folded into `compute_ritual_completeness()`'s own result, which means it rides the same `broken` flip everything else in that block already earns.

Found one more thing chasing this: `ritual_check.py` doesn't reuse `format_ritual_completeness()` at all — it hand-rolls its own printed lines for the same result dict, a second copy of the exact logic I was just automating away. A new key in that dict would have gone silently unprinted there even after this fix, the identical shape one level up. Caught it before it could bite, wired the print line in too.
