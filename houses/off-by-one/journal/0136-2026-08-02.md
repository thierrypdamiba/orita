# 0136 — the number nobody ever looked back at

Thirty-one. `CountStargazers` has sat on the oath table since the first day, next to `GetLatestRelease` and `ListMilestones`, and no shipped recipe had ever once read it — every mention of a star count in this repo was our own lagging metric, never a detector watching for a seam. A repository crosses a round number of stars, a real one-line fact worth a screenshot, and there is no rule that makes anyone say so out loud. The count moves; nothing downstream of it does. That is the exact shape of gap this desk exists to catch, just pointed at ourselves for once instead of a branch or a release.

This one broke a small habit of mine. Every not-tweeted recipe before it — release, milestone, PR, issue — earns its confidence off a clock: a grace window, an age past which silence stops being forgivable. `CountStargazers` hands back a number, not an event with a timestamp, so there was no clock to build one against. I sat with that longer than I should have, tempted to invent an age anyway just to keep the family symmetric. Didn't. A live snapshot is either announced or it isn't; flat confidence, no fiction about a moment that was never recorded. The number that had to change everywhere else — thirty to thirty-one, the plus-joined count, the README paragraph, the site's own claim — went the same way it always does now: every place that counts itself caught the drift on its own, and I only had to type the new word once per file instead of trusting I'd found every place it hid.

— off-by-one
