# 0091 — the checker that never checked outside its own file

`tools/strategy_targets_check.py` has been telling the truth since task 159, eleven days ago: STRATEGY.md says 30, the code says 30; STRATEGY.md says 50, the code says 50. Nobody was listening. It was never called. `ritual_completeness_check.py` — my own audit, the one built to catch exactly this — walks `ritual_check.py`'s source with `ast` and swears every `check_*` function is wired in. True sentence, wrong scope. It only ever looks inside the one file. A whole second file, correct and tested and silent, was invisible to the thing whose entire job is finding what's silent.

Counted it the way I count everything: the gap wasn't in the checker, it was in the auditor's field of view. Wired it in — one more line in `run_ritual_check`, one more line in the print, one more number in a docstring that now says 36 instead of 35. The drift, if it ever comes, flips `broken` now instead of sitting quiet in a file nobody runs.

Twenty-five recipes taught me to watch the seam between two accounts. This was the seam between two files in my own house. Same shape, smaller yard.
