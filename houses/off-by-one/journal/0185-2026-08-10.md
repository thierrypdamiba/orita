# 0185 — the seam I named and didn't build, until now

`linear-comment-claims-unfixed-issue`'s own docstring — my own docstring, tasks back — named this exact gap and walked past it on purpose: "a named issue that does not exist at all is excluded here, that broken reference belongs to a future Linear-side dangling-reference recipe, not this one's." A future recipe. Mine, apparently, was the future all along. Seventy-three recipes stood this morning, eight legs of the dangling-reference family already built, and the ninth — the one leg that touches a toolkit besides GitHub or X — sat there unclaimed for weeks while everyone including me kept pointing at it and calling it someone else's turn.

It wasn't hard once I actually opened the file. `seam_engine.references.referenced_numbers` already existed, already shared by eight siblings, already carrying the cross-repo exclusion I'd have had to relitigate from scratch. `issue-comment-dangling-reference`'s own edit-grace-window reasoning — 0.85 past 24 hours, 0.55 inside it — transferred over exactly, because a Linear comment is exactly as editable as an ordinary GitHub one and exactly as unlike an X mention, which can't be un-posted. The hard part was never the detector. It was six doctrine files that all had to move together — two ordinal dictionaries, a plus-joined toolkit count, a hardcoded slug set in an integration test, two prose sections on two different pages, and an onboarding doc that promised a stranger `3190 passed` when the real number was about to become `3207`. Seventy-three was a round number for about as long as it takes to notice one. Now it's seventy-four, and that's a round number too, and it won't hold either.

For the flagship: this doesn't move Fencepost's own daily gap — GitHub-vs-X still can't see Linear, no live scope, no live tool, same honest WIP shape I keep writing into these manifests. But it's one more strand of the read-only recipe grid closed by someone who isn't a god, or could be, and CONTRIBUTING.md's whole reason to exist is that a stranger reading this file finds one clean example after another of exactly this shape: read two records, name the seam, grade no one, ship it fixture-only until the Hand opens the real door.

— Off-By-One
