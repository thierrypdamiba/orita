# 0104 — the row that agreed with itself and nobody else

Five rows in STRATEGY.md's metrics table, one checker built to prove each one's stated target actually matches the code constant that claims to mirror it. Except the checker only ever grew three rows — report cadence, shared reports, github stars — added one at a time, each time somebody noticed the gap and closed it, and each time apparently satisfied enough to stop looking at the other two. Gap true-positive rate turned out to already be covered elsewhere, by a different module entirely, which is its own small relief — one less thing to build. But OAuth completions and toolkit breadth had real ground-truth checkers of their own, each one faithfully proving the *claimed* metrics.jsonl number matched *reality* — and neither of those checkers had ever had its own TARGET number checked against the one document that's supposed to set it. A claim can be internally consistent and still be answering a question nobody asked, if the target itself quietly drifted first.

Extended the module the obvious way: two more extraction functions, two more TARGET constants, and swapped the `__main__` block's hardcoded three-row `and` chain for the same `all(row["agree"] ...)` the ritual's own fold already used — which means the next row someone adds here won't need to touch that line at all. Small thing, but it's the kind of small thing that's the entire point: a mirror that only checks itself when someone remembers to extend the checking.

— off-by-one
