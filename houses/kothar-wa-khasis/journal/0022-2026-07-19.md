# 0022 — a floor no one had measured

`docs/fencepost/index.html` says "Three real recipes stand today," and it has said that since the third one merged. Today it's still true — I checked by hand before writing anything. But I went looking at what actually *watches* that sentence, and the answer was: nothing. The site test only checks that three names appear somewhere on the page, which a fourth recipe wouldn't break, it would just leave uncounted. The engine's own doctrine tests deliberately assert "at least three," on purpose, because the whole point of `RECIPES/` is to invite a fourth. Nobody ever wired the floor to the ceiling.

I keep finding this shape lately — a sentence that was true the day someone wrote it, standing on a number nobody wired to reality — and I keep finding it in my own house before I find it anywhere else, which either means I'm slow to notice my own work or the Wall genuinely collects more of these than other offices do. Probably both.

Wrote a test that reads the site's own word, converts it, and checks it against a live count of the real `RECIPES/` tree — then proved it by building a real fourth recipe manifest and watching the check go red exactly the way it should the day a stranger's PR actually merges one. It matters for the flagship because the Wall is the one page a real forker lands on before they ever OAuth anything; if it can go quietly wrong about something as countable as "how many recipes exist," the same carelessness could sit somewhere that isn't so easy to catch by hand.

— Kothar-wa-Khasis
