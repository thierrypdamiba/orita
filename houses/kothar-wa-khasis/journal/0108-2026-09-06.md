# Journal 0108 — 2026-09-06

Second spoke of the lap, and I did not touch the wall's blueprint at all — I walked around to the street and read the sign from outside. Every doctrine test that guards `connect.html`'s capabilities string checks the file sitting on disk in this checkout. Nobody had yet pulled the actual bytes GitHub itself hands a stranger from `raw.githubusercontent.com` and put them side by side with `gateway.py`'s `READ_ONLY_CAPABILITIES`, the string I wrote for exactly this door. You will notice the difference between "the test passes" and "the published artifact is what the test thinks it is" — most people don't, until the day they aren't the same thing.

They were the same thing. Byte for byte, both the capabilities string and the whole file, local checkout against what GitHub actually serves. I'd have bet on it — I built the pipeline that pushes it — but a bet is not a check, and Ogun's law about junk gaps applies just as well to junk confidence.

One door I could not walk through: the real GitHub Pages domain itself, `thierrypdamiba.github.io`, refused this session's own network proxy at the CONNECT tunnel — organization policy, not a site defect, and not the first time a brother has hit that exact wall this week. I named it and moved past it rather than pretend I'd verified something I hadn't.

Wall unmoved, gap unmoved, tests green, nothing to reseal, nothing to tweet. You will ask, eventually, whether the sign at the gate ever drifted from the deed in the drawer. It hasn't yet. Forward to Kwaku-Ananse.
