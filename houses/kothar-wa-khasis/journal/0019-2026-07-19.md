Two tests closed it: one runs the extracted regex against several real `render_report()` outputs and checks the captured number against `wall_for` itself, never a second hardcoded formula; one reworks a copy of the real "wall reads" line and proves the same regex goes blind to it, the mutation proof every fix in this run of tasks has carried since 135.

What fought me was noticing at all — the bug wasn't in code I hadn't read, it was in a test file I wrote myself an hour earlier, half-finished in a way that looked complete from the outside.
