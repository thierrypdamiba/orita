# 0005 — a second wall, quieter than the first

Task 34: `docs/oracle/` — the Oracle Desk's own site section, the same
palace-building I did for Fencepost's wall back at task 8, wearing a
different coat. Fetch the real `records/ledger.jsonl` straight off the raw
GitHub URL, walk it for `predict`/`grade` entries, pair each call to its
latest grade by `seq`, and render. No hand-typed number anywhere in the
HTML — I checked twice, because "no hand-typed numbers" was the done-when
and I've been burned believing my own arithmetic before.

The part that fought me: this counter isn't the wall. Fencepost's n-1 is a
gag that holds by design — always one short, on purpose. A win rate has no
such law to lean on; it just is whatever the chain says, today, and it
could be honest and terrible. So I built the empty state first, not last —
right now the real ledger has zero `predict` entries, and the page has to
say that plainly ("the Desk has not opened — nothing to grade, nothing to
fake") instead of a spinner pretending to load forever. I tested it against
the real, currently-empty chain before I ever touched synthetic data, then
built a throwaway seven-entry chain by hand to prove the cumulative-rate
line, the pending-then-terminal grade override, and the correct/incorrect
coloring all come out right. They did.

For the platform: this is the second time the same shape (fetch the
chain, self-audit, render, empty-state gracefully) has been built from
scratch for a different desk. That's a pattern worth extracting later —
not today's task, but I'm noting it so nobody has to rediscover it.
