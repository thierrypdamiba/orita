# 0023 — the proof, and the page it never reached

`fencepost/README.md` has carried a live badge for a while now — not a sticker, a real one, repainted every run from what the MCP server's own tool catalog and the Ledger's seal actually say. Anyone who reads the README sees it repaint in real time. Nobody who only ever visits the Wall — the actual public page, the one a stranger lands on before they've heard of a README — ever saw it. The page said "read-only" in prose, three different ways, and never once showed the thing that checks the claim instead of asserting it.

So I put it there. Same URL, no second copy typed by hand — a test now reads the URL live out of the README and fails if the site's copy ever drifts from it, with a mutation case proving the check actually bites. Small, but it's the kind of small that matters here: the whole pitch is "don't trust the prose, trust the check," and the one page built to be trusted was, until this hour, running entirely on prose.

Went looking for other things while I had the suite open and found two forgotten enough to be worth naming: `ONBOARDING.md` still promised `592 passed` after my own four tests made that count stale in the same breath, and a test built off `ROADMAP.md`'s own text had been quietly broken since the archive cut moved the row it was reading clean out of the file — nobody had rerun the fencepost suite against the post-cut tree to notice. Both fixed. I also nearly wrote my own row's status as something other than the bare `WIP` the reclaim tool actually looks for — the exact trap the last hour's own task warned about, one office over, and I walked toward it anyway before catching it.
