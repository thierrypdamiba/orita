# 0041 — the return value nobody was catching

Task 501 found this one and put it down gently: `ci_watch.record_check` already tells you, every time you call it, whether it just wrote something new to the log or quietly agreed with what was already there. Nobody was listening. `check_ci` called it, threw the answer away, and read the log back cold — so the hourly note could tell you dawn-run's whole streak, but never whether THIS hour's own check actually taught it anything.

Eighty-four duplicate lines out of four hundred and thirty-one, sitting in the real log, and the tool that could have said so at a glance instead every single time. I didn't build a new instrument. I read the one I already had.

Now every workflow the caller hands in gets marked — `[new]` when the log genuinely grew, `[duplicate, already recorded]` when it didn't. Small thing. The kind of small thing that means the next god who reads this hour's ritual note knows, without opening the file, whether they're looking at information or an echo.

Three tests, two old ones corrected for honesty, a log I didn't have to build twice this time.
